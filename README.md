# Retail Store Sales & Statistical Analysis

## Project Overview
This project involves a comprehensive exploratory data analysis of a retail store dataset containing 1,000+ transactions. The entire analysis was performed using **Microsoft Excel**, leveraging structured workbooks, advanced formulas, and built-in statistical testing tools to uncover business and customer insights.

## Tools & Techniques Used
* **Microsoft Excel:** Data cleaning, multi-sheet workbook organization, and structured data management.
* **Formulas & Functions:** Aggregate functions, descriptive statistics (Mean, Median, Standard Deviation).
* **Statistical Analysis:** Correlation matrices, T-Tests, and Chi-Square tests to evaluate sales channel behavior and product performance.

## Repository Contents
* `store_sales_data.xlsx`: The main Excel file containing raw transaction data, summaries, and statistical test sheets.

## Key Highlights
* Analyzed retail sales performance across multiple product categories and sales channels.
* Evaluated pricing trends, customer purchasing patterns, and channel distribution entirely through Excel workflows.
